# This project is for the Requrement of Assignment 1 of Next Level Web Dev course by Programming Hero

### Description:

This assignment comprises various problems that demonstrate fundamental `TypeScript` concepts, including `data typing`, `interfaces` for `objects`, `class usage with inheritance`, `type checking`, and `manipulation of data structures`. The solutions aim to showcase efficient and clear problem-solving techniques using `TypeScript`, adhering to best coding practices.

### Topic Covered:

- Basic Types
- Types for complex data type like arrays and objects
- Special types for TS like void, never, unknown, tuple, any
- Generics, Generics with function, generics with Interface
- OOP in TS specially class and ineritence
- Literal types, union
- Type alias vs. Interface
- Type Guard/Type Narrowing
- **Advance Topic** like Type assertion, mapped types, conditional types, utility types etc.
